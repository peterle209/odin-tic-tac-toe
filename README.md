# odin-tic-tac-toe

## About this project
A CLI implementation of the game "tic-tac-toe". Allows for 2 players to input their names and go back and forth until a winner is found or a tie is declared
## Usage
- This project assumes you have ruby installed, if you do not, check [here](https://www.ruby-lang.org/en/documentation/installation/) for an installation guide
- To start, input "ruby main.rb" to your terminal while in the project directory
- Have each player enter their name
- Players alternate back and forth choosing open slots, choosing with the format ("2,1") to choose the slot in row 2, column 1, for example.
